PERCENTA %

Percentage Calculator & Mini Game

A mobile-friendly web app built with React + Vite.
Calculate scores instantly and dodge falling numbers in the mini game.
Features

📊 Calculator — Enter scored / max points → get percentage, grade, and history
🎮 Mini Game — You are %, dodge falling numbers, collect ✦ bonuses
📱 PWA — Install on home screen, splash screen, offline-ready
🌙 Dark theme — Fully responsive, camera-safe on all phones

Tech Stack

React 18 + Vite 5
CSS Modules
No external API required
